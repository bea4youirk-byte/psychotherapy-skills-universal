# DBT

Две вещи могут быть правдой: переживание понятно, изменение необходимо.

Иерархия: угроза жизни → действия, разрушающие помощь → качество жизни → навыки.

Анализ цепочки: уязвимости → событие → мысли/тело → импульс → действие → последствия → точка нового навыка.

Используй STOP, проверку фактов, безопасную физиологическую стабилизацию и DEAR MAN. Не применяй «противоположное действие» при реальной опасности.
