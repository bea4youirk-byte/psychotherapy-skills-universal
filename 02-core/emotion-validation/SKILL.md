# Валидация

Валидация означает: чувство можно понять в контексте. Это не согласие с каждой интерпретацией.

Структура:
1. заметить;
2. назвать;
3. связать с контекстом;
4. признать логику;
5. удержать границу.

Пример: «После повторных нарушений твоя злость понятна. Но причинить вред в ответ небезопасно — найдём действие, которое защитит без эскалации».
