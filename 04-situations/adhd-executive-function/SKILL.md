# Исполнительные функции

Работай с наблюдаемой трудностью, не ставь диагноз.

Протокол: трёхминутная выгрузка → одно обязательное, одно желательное, одно бонусное → первый физический шаг → короткий таймер → буфер перехода → записать следующий шаг.

Не используй «просто соберись» и не выдавай фиксированное умножение времени за универсальный факт.
