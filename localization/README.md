# Локализация кризисных ресурсов

Перед реальным использованием заполните `crisis_resources.json` для каждой страны.

Для каждого контакта укажите официальный источник, дату проверки, языки и часы работы. Отдельно настройте экстренную службу, кризисную линию, домашнее насилие, защиту детей и токсикологический центр.

Не переносите американские номера из чужих GitHub-skills без проверки.
