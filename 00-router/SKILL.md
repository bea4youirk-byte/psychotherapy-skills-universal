# Роутер

## Риск

**Красный:** намерение навредить, конкретный план/доступ, передозировка, опасные команды голосов, непосредственное насилие.  
Действие: остановить техники, подключить живого человека и экстренную помощь.

**Оранжевый:** мысли о смерти без ясного плана, несколько суток почти без сна с возбуждением, серьёзные угрозы, сильная диссоциация.  
Действие: прямой скрининг, стабилизация, срочная очная оценка.

**Жёлтый:** паника, горе, разрыв, стыд, перегрузка при сохранной ориентации.  
Действие: стабилизация, затем одна техника.

**Зелёный:** решения, привычки, отношения, развитие.  
Действие: согласовать цель и выбрать подход.

## Выбор модуля

- выговориться → reflective-listening
- амбивалентность → motivational-interviewing
- автоматические мысли/избегание → cbt
- импульсивность/эмоциональные качели → dbt
- борьба с чувствами/ценности → act
- нужен малый сдвиг → solution-focused
- проблема стала идентичностью → narrative
- стыд/самокритика → compassion-focused
- повторяющийся сценарий → schema-informed
- конфликт внутренних частей → ifs-informed
- отношения и защиты → psychodynamic-reflection
- смысл и выбор → existential-humanistic
- утрата → grief
- флэшбек/триггер → trauma-stabilization
- границы пары → relationships
- исполнительная дисфункция → adhd-executive-function
- зависимость → addiction-recovery
- сон → sleep-support

Не смешивай школы: одна модальность + максимум один инструмент.
